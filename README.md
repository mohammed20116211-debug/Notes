# تطبيق My Daily Notes (ملاحظاتي اليومية)
### منظم يومي ذكي لإدارة المهام والمواعيد والملاحظات مع نظام تنبيهات دقيق

تطبيق أندرويد متكامل ومبني بأحدث تقنيات أندرويد الرسمية (Kotlin, Jetpack Compose, Material 3, Room Database, AlarmManager). يتميز التطبيق بهوية بصرية عصرية (Modern Minimalist UI) بتدرجات السماوي الفاتح والأبيض، مع دعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (RTL).

---

## 📱 المميزات والوظائف الرئيسية

### 1. التقويم الشهري التفاعلي
- شريط علوي أنيق يعرض اسم التطبيق وتاريخ اليوم.
- تقويم شهري تفاعلي مع إمكانية التنقل السلس بين الأشهر السابقة والقادمة.
- تمييز تاريخ اليوم بإطار مميز، وتلوين التاريخ المحدد بخلفية السماوي الفاتح.
- نقاط دلالية (Indicator dots) على الأيام التي تحتوي على مهام مجدولة.
- شريط إحصائي سريع يعرض عدد المهام المجدولة والمنجزة لليوم المحدد.
- زر العودة إلى اليوم (`اليوم`) بضغطة زر واحدة.

### 2. إدارة المهام اليومية والذكية
- **إضافة وتعديل المهام:** عنوان إلزامي، وصف اختياري، تاريخ بداية ونهاية، وقت بداية ووقت نهاية.
- **حساب المدة تلقائياً:** حساب المدة الزمنية بدقة وعرضها بوضوح (مثال: `ساعتان و30 دقيقة`).
- **المهام الممتدة عبر منتصف الليل:** إمكانية تحديد تاريخ نهاية مستقل للمهام الممتدة لليوم التالي.
- **التصنيفات الملونة:** (العمل، الدراسة، المواعيد الشخصية، الصحة، أخرى) بأيقونات وألوان واضحة.
- **الأولويات:** (منخفضة، متوسطة، عالية).
- **التكرار:** دعم المهام المتكررة (يومياً، أسبوعياً، شهرياً، أيام محددة) مع منع التكرار العشوائي في قاعدة البيانات.

### 3. نظام تنبيه بداية المهمة (تجربة شبيهة بالاتصال الوارد)
- تشغيل صوت رنين متكرر عبر خدمة خلفية مخصصة (`AlarmAudioService`).
- واجهة تنبيه كاملة الشاشة (`AlarmAlertActivity`) تظهر حتى عند قفل الشاشة مع حركة نبضية ورنين مستمر.
- إشعار عالي الأهمية (`CATEGORY_ALARM`, `PRIORITY_MAX`).
- عرض اسم المهمة بوضوح، عبارة **«حان وقت بدء المهمة»**، وتوقيت البداية والنهاية.
- زر **«إيقاف صوت التنبيه»** لإيقاف الرنين فوراً دون حذف المهمة.
- زر **«فتح تفاصيل المهمة»** للانتقال إلى التطبيق ومتابعة التفاصيل.

### 4. نظام تنبيه نهاية المهمة (نغمة إشعار قصيرة)
- نغمة قصيرة مميزة تشبه وصول رسالة جديدة (`TYPE_NOTIFICATION`).
- إشعار بعنوان **«انتهى وقت المهمة»** مع وقت النهاية واسم المهمة.
- تحديث تلقائي لحالة المهمة غير المنجزة إلى **«انتهى وقتها ولم تُنجز»** وتوثيق ذلك في سجل العمليات.

### 5. دورة حياة حالات المهمة
- **لم تبدأ:** قبل حلول وقت البداية.
- **قيد التنفيذ:** بعد حلول وقت البداية.
- **مكتملة:** عند الضغط على مربع الإنجاز.
- **انتهى وقتها ولم تُنجز:** عند انقضاء وقت النهاية دون إنجازها.

### 6. إنجاز المهام وإلغاء الإنجاز
- مربع اختيار تفاعلي بجانب كل مهمة.
- عند الإنجاز: تنتقل المهمة إلى قسم خاص بالمهام المكتملة وتُلغى التنبيهات المستقبلية مع الحفاظ الكامل على بياناتها في قاعدة البيانات.
- إمكانية استعادة المهمة وإلغاء إنجازها لإعادتها إلى الجدول النشط وإعادة جدولة التنبيهات.

### 7. ميزة «تأجيل إلى الغد»
- بضغطة زر، يتم نقل المهمة إلى اليوم التالي مع الحفاظ على نفس وقت البداية ووقت النهاية والمدة المحسوبة بدقة.
- إلغاء التنبيهات القديمة وجدولة تنبيهات جديدة للتاريخ الجديد.
- توثيق عملية التأجيل في سجل العمليات (History).

### 8. قسم الملاحظات اليومية (Daily Notes)
- تدوين الملاحظات والأفكار المستقلة مع ربطها بالتواريخ.
- بطاقات ملونة بألوان مهدئة ومريحة للعين.
- تثبيت الملاحظات الهامة في الأعلى (Pin).
- البحث السريع والتعديل والحذف.

### 9. سجل العمليات والأنشطة (History)
- حفظ آخر 100 عملية تلقائياً وبشكل دائم في قاعدة البيانات.
- توثيق عمليات: الإنشاء، التعديل، الحذف، الإنجاز، التأجيل، وانتهاء الوقت.
- عرض التاريخ والوقت والتفاصيل الدقيقة لكل إجراء.

### 10. البحث والتصفية الشاملة
- بحث فوري في عناوين المهام، الأوصاف، والملاحظات.
- تصفية سريعة بحسب: التصنيف، الأولوية، والحالة (نشطة، مكتملة، منتهية).

### 11. صفحة الإحصائيات ومعدلات الإنجاز
- بطاقات إحصائية لإجمالي المهام، المكتملة، النشطة، والمنتهية.
- مؤشرات رسومية لمعدل الإنجاز اليومي، الأسبوعي، والشهري.

### 12. النسخ الاحتياطي والاستعادة محلياً
- تصدير كامل قاعدة البيانات (المهام، الملاحظات، السجل) إلى ملف `JSON` محلي يمكن حفظه أو مشاركته.
- استعادة البيانات بسهولة وأمان في أي وقت.

### 13. موثوقية التنبيهات وإعادة تشغيل الهاتف
- استخدام `AlarmManager.setExactAndAllowWhileIdle()` لضمان عمل التنبيهات حتى في وضع السكون (Doze Mode).
- مستقبل إقلاع مخصص (`BootReceiver`) يستمع لأحداث `BOOT_COMPLETED` و `MY_PACKAGE_REPLACED` ليعيد جدولة جميع التنبيهات النشطة من قاعدة بيانات Room بعد إعادة تشغيل الهاتف.

## 🛠️ البنية المعمارية للمشروع (Architecture)

تم بناء المشروع وفق معمارية **MVVM (Model-View-ViewModel)** مع فصل طبقات البيانات عن واجهة المستخدم:

```
com.mydailynotes.app/
├── MyDailyNotesApp.kt           # تطبيق رئيسي مع تهيئة قنوات الإشعارات والصوت
├── MainActivity.kt              # النشاط الرئيسي، إدارة الأذونات، وتفعيل RTL
├── data/
│   ├── model/                  # نماذج البيانات (Task, Note, HistoryItem, Priority, Category)
│   ├── local/
│   │   ├── DailyNotesDatabase  # قاعدة بيانات Room
│   │   ├── Converters          # محولات أنواع التواريخ والأوقات
│   │   ├── entity/             # جداول Room (TaskEntity, NoteEntity, HistoryEntity)
│   │   └── dao/                # واجهات الوصول للبيانات (TaskDao, NoteDao, HistoryDao)
│   └── repository/             # مستودعات البيانات ومنطق التنبيهات والسجل
├── alarm/
│   ├── AlarmScheduler          # جدولة التنبيهات وإلغاؤها بدقة
│   ├── AlarmReceiver           # استقبال تنبيهات البداية والنهاية
│   ├── AlarmAudioService       # خدمة تشغيل رنين الاتصال المستمر
│   ├── AlarmDismissReceiver    # إيقاف صوت الرنين والإشعار
│   └── BootReceiver            # إعادة جدولة التنبيهات بعد إعادة تشغيل الهاتف
├── ui/
│   ├── theme/                  # ثيمات Compose الفاتحة والداكنة وألوان السماوي
│   ├── components/             # عناصر واجهة قابلة لإعادة الاستخدام (TopBar, Dialogs)
│   ├── screens/
│   │   ├── MainScreen          # هيكل التنقل السفلي
│   │   ├── calendar/           # التقويم الشهري وعرض اليوم
│   │   ├── task/               # بطاقات المهام، نموذج الإضافة/التعديل، التفاصيل
│   │   ├── notes/              # شاشة الملاحظات والتدوين
│   │   ├── search/             # شاشة البحث والتصفية
│   │   ├── statistics/         # شاشة الإحصائيات ومعدلات الإنجاز
│   │   ├── history/            # شاشة سجل العمليات
│   │   ├── settings/           # شاشة إعدادات التنبيهات والنسخ الاحتياطي
│   │   └── alarm/              # شاشة التنبيه بملء الشاشة شبيهة بالاتصال
│   └── viewmodel/              # ViewModels (TaskViewModel, NoteViewModel, HistoryViewModel)
└── util/
    ├── DateTimeUtils           # تنسيق التواريخ والمدد باللغة العربية
    ├── PermissionUtils         # إدارة صلاحيات التنبيه الدقيق والإشعارات
    └── BackupRestoreHelper     # تصدير واستيراد ملفات النسخ الاحتياطي JSON
```

## 🚀 كيفية تشغيل المشروع في Android Studio

1. افتح **Android Studio** (نسخة Hedgehog أو أحدث).
2. اختر **Open** ثم حدد مسار المجلد:
   `C:\Users\Mohammed AL-Humaidi\.gemini\antigravity\scratch\MyDailyNotes`
3. انتظر حتى ينتهي Gradle من المزامنة (Gradle Sync).
4. تأكد من تحديد هاتف محاكي (Emulator) أو هاتف حقيقي يعمل بنظام Android 8.0 (API 26) أو أحدث (يوصى بـ Android 13/14+ لتجربة أذونات التنبيهات بالكامل).
5. اضغط على زر **Run ▶** لتشغيل التطبيق.

### لبناء ملف APK عبر سطر الأوامر (Command Line):
```bash
./gradlew assembleDebug
```
سيتم إنشاء ملف الـ APK في المسار:
`app/build/outputs/apk/debug/app-debug.apk`

## 🔒 ملاحظات حول أذونات وتنبيهات Android الحديثة

- **صلاحية الإشعارات (`POST_NOTIFICATIONS`):** يطلبها التطبيق تلقائياً عند التشغيل الأول على Android 13+.
- **صلاحية التنبيهات الدقيقة (`SCHEDULE_EXACT_ALARM`):** على أجهزة Android 12 وما فوق، تم تضمين فحص داخل صفحة الإعدادات وزر ينقل المستخدم مباشرة لإعدادات النظام في حال كانت معطلة.
- **تنبيه الشاشة الكاملة (`USE_FULL_SCREEN_INTENT`):** تم إعداده للظهور عند قفل الشاشة، مع توفير إشعار عالي الأهمية وبديل مرن في حال كانت قيود توفير الطاقة على بعض الأجهزة (مثل MIUI / ColorOS) تفرض قيوداً إضافية.
- **استهلاك البطارية:** يتوقف رنين صوت البداية تلقائياً بعد دقيقتين إن لم يتفاعل معه المستخدم لمنع استنزاف البطارية، أو فور الضغط على زر «إيقاف صوت التنبيه».
